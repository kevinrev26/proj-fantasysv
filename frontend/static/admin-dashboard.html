Data Management

Bulk import entities via CSV

🔑

Import Seasons

Headers required: name, start_date, end_date
Format: YYYY-MM-DD for dates.

Import Matchdays

Headers required: season_id, name, deadline_utc
Format: deadline_utc is optional (e.g. 2026-08-15T12:00:00Z).

Import Leagues

Headers required: season_id, name

Import Teams

Headers required: league_id, name

Import Players

Headers required: team_id, name, position, tier, credit_value
Values constraint: position (GK, DF, MF, FW), tier (A, B, C, D).

Update Players

Headers required: player_id
Optional params: is_active, credit_value, tier (only provided ones will be updated).

Import Tournament Phases

Headers required: season_id, name
Valid phase names: round_of_64, round_of_32, round_of_16, group, quarterfinal, semifinal, final

Export Players

Downloads a CSV file with columns: player_id, name, team_name.
Optionally filter by season to limit results to teams in that season's leagues.
player_id name team_name
